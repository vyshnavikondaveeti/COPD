### COPD Lung Explorer – Project Description

COPD Lung Explorer is a Python Flask-based educational web application designed to help students, researchers, and hackathon participants understand Chronic Obstructive Pulmonary Disease (COPD) through interactive visualizations and symptom-trend monitoring.

The application explains three major aspects of COPD: small-airway obstruction, emphysema, and chronic bronchitis. It uses interactive sliders, airway illustrations, alveolar comparisons, and animations to demonstrate airway narrowing, inflammation, fibrosis, mucus accumulation, alveolar wall destruction, reduced elastic recoil, and air trapping.

The system also includes a patient monitoring dashboard where users can record symptoms such as breathlessness, cough severity, sputum level, activity level, SpO₂ (optional), FEV1, and FVC. Using Python Flask, SQLite, and SQLAlchemy, the application stores monitoring records and displays historical trends through interactive Chart.js graphs. A simple analysis feature highlights changes from the user's own baseline without diagnosing diseases or predicting medical emergencies.

Built using Python, Flask, HTML5, CSS3, JavaScript, Bootstrap, SQLite, SQLAlchemy, and Chart.js, COPD Lung Explorer provides a responsive and user-friendly interface suitable for educational demonstrations and hackathon presentations.

Main objective: To improve understanding of COPD-related lung changes through interactive visual learning and basic symptom-trend tracking.

Safety statement: Educational prototype — not a medical diagnostic or treatment system. All visualizations are conceptual, and users should consult qualified healthcare professionals for medical evaluation.
